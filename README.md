# Portfolio

A static portfolio site with a recruiter-facing landing page and three public-safe case studies:

- Career Knowledge System
- Career Knowledge Extraction
- Controls

The live site uses shared styling, page-specific styles, lightweight scripts, and public-safe assets. Local review notes and development tooling are retained for workspace use and are not part of the published site.

For deployment, include only the live landing page, case-study pages, required styles, scripts, and assets.
